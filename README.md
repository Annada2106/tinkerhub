# TinkHack – TinkerHub MEC Landing Page

## Overview
This is the official landing page for **TinkHack**, the flagship AI-based hackathon organized by **TinkerHub MEC**.  
The page provides an interactive, modern, and dark-themed interface with animations, smooth scrolling, and responsive design.

---

## Features
- **Dark Theme:** Modern dark pastel aesthetic with maroon and white accents.
- **Responsive Design:** Works seamlessly on mobile, tablet, and desktop devices.
- **Hero Section:** Animated hero banner with text and call-to-action button.
- **Animated Sections:** Fade-in and slide animations on scroll for Overview, Timeline, Registration, Sponsors, and Contact sections.
- **Interactive Buttons:** Hover effects with color transition and scaling.
- **Sponsors Grid:** Hover scaling and brightness effect for sponsor logos.
- **Smooth Scrolling:** Clickable navbar items scroll to respective sections.
- **Footer:** Clean and consistent with dark theme.

---

## Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript** (for scroll animations and interactive elements)
- **Google Fonts** (Montserrat, Poppins, Roboto)
